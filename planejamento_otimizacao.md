# Planejamento de Otimização - InvestBet Capital

## 1. Identidade Visual (Paleta de Cores)
Baseado na logo, utilizaremos tons de verde profundo e dourado para transmitir riqueza e sorte.

| Elemento | Cor (Hex/Oklch) | Uso |
| :--- | :--- | :--- |
| **Verde Primário** | `#002a1a` / `oklch(0.20 0.05 160)` | Fundo principal, seções de destaque |
| **Dourado/Ouro** | `#d4af37` / `oklch(0.75 0.15 80)` | Botões, ícones, bordas de destaque |
| **Verde Médio** | `#004d33` / `oklch(0.30 0.08 160)` | Cards, elementos secundários |
| **Texto Claro** | `#fdfcf0` / `oklch(0.98 0.01 80)` | Textos sobre fundos escuros |

## 2. Menu Fixo (Referência BI7)
- **Comportamento:** `sticky top-0`, com leve transparência ou desfoque (`backdrop-blur`).
- **Estilo:** Fundo verde escuro, borda inferior dourada fina.
- **Interação:** Links com hover em dourado.
